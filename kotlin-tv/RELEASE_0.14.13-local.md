# 红果 TV 0.14.13-local

版本 `0.14.13-local`，versionCode `28`，最低 Android 8.0 / API 26。APK 使用与本仓库旧版相同的本地测试签名，覆盖安装需系统确认。

## 红果账号

- 设置 → 红果账号：用手机红果短剧 App 扫码并在手机确认，查看同步状态或手动同步。
- 同步电视与手机的观看集数、播放位置。先完整拉取并核对账号，再按记录时间合并、上传；失败进度保留在本机等待重试。设备时间明显不准时先提示校时。
- 登录前的游客记录不会自动上传，可由用户选择合并；退出后显示游客记录。收藏、手动标记已看和删除历史是本机功能，不同步到红果账号。
- 账号登录资料由 Android Keystore 加密保存在本机；接口变化或无法确认剧集资料时显示状态并保留待同步进度。
- 官方历史接口的时长字段可能是整部剧总时长。云端记录在无法确认单集时长时不绘制单集进度百分比；实际播放后使用播放器取得的时长。

## 验证与限制

在用户授权的真实红果账号上，用手机 App 扫描 Android TV 模拟器二维码并确认；应用重启后保留登录状态。模拟器和手机对同一部已有观看记录的短剧，分别确认了电视写入后手机可见、手机改变进度后模拟器及云端可见。另在模拟器首次播放一部账号此前没有记录的短剧，官方云端读回相同集数及约 15 秒的位置。

190 项核心测试通过；Android 构建成功，Lint 为 0 错误、35 警告。Android TV API 36 模拟器中验证了账号安全存储、扫码窗口、账号与游客记录隔离、待上传记录重启保留、Android 数字 ID 编码及弹窗生命周期。在独立模拟器上从 0.14.9 覆盖安装，收藏和一条测试观看记录保留。包含实际账号的模拟器覆盖安装后仍显示已登录和同步完成。

账号、历史同步使用非官方接口，平台可能调整接口；无法保证所有剧集、所有账号和网络条件都可用。实体电视、Android 8 实机和长时间运行尚未验证。自动更新使用既有 GitHub Release 渠道，是否可达取决于电视网络；需要用户在系统安装器中确认，不能静默安装。
