# 红果 TV 0.14.8-local

本版修复上游播放接口对未注册设备返回 HTTP 200、空正文的问题。播放前会按上游当前协议注册一次匿名播放设备，在进程内复用 `device_id`、`install_id` 和必要的白名单 Cookie，再请求 `multi_video_model/v1`；不会保存账号凭据、设备令牌或完整注册响应。

注册后的播放模型优先解析当前接口直接返回的 `video_list`，只有旧模型没有直接片源时才访问 `fallback_api`。保留同清晰度备用地址、Range 重试、Media3 播放缓存、后续内容预取和缓存大小设置。

版本：`0.14.8-local`，versionCode `22`，最低 Android `26`。自动更新仍要求 APK 与电视当前安装包使用同一签名；首次接入更新渠道需要允许安装未知来源应用并确认系统安装。

验证：核心 JVM 测试通过；真实上游播放探针四个样本均取得 MP4 `ftyp` 首段和完整长度；Android Debug Lint 与 Debug APK 构建通过。没有实体电视连接，长期弱网、芯片解码和系统安装仍需在目标电视上复测。
