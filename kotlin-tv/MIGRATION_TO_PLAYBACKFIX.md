# 原签名丢失后的迁移与更新

**2026-11-23 发布状态提醒：** GitHub 最新公开的 [`0.14.18-local` 原版 Release](https://github.com/seanshigit/hongguoTV-livingroom/releases/tag/tv-v0.14.18-local) 声称可用原签名覆盖 0.14.15。此声明晚于此前“原版私钥丢失”的记录，但发布页文字本身不等于实物验签。应先独立核对新旧 APK 的包名、签名证书 SHA-256（原版应为 `2a569cd27ab064123d8a407442d87931abfdca3329e0c1889a44929060f2718a`）、版本码与原版更新清单，成功后优先同签名原地覆盖；不能验签或系统拒绝覆盖时，才按照下文迁移到独立版，切勿为升级先卸载原版。

此前报告过原版签名私钥丢失。若确实无法使用原签名制作新版，就不能用不同私钥或包名原地覆盖已安装的原版；签名证书、历史 APK 和源代码都不能自行恢复原私钥。

后续使用「红果 TV 播放修复版」`com.hongguotv.nativeapp.playbackfix` 及已经保留的固定签名。本次安装包为 `0.14.18-playbackfix` / versionCode `33`，包含播放、连续换集和应用内更新修复。它可以和原版并存；不要为安装修复版先卸载原版。

## 第一次迁移

1. **在旧版保存本机备份。** 手机和电视连接同一局域网；旧版打开「设置 → 片单与设备 → 手机备份与恢复」。手机扫描二维码，点击「下载电视备份」，保存 `hongguotv-library.json`。
2. **安装播放修复版。** 已有 `0.14.16-playbackfix` 或 `0.14.17-playbackfix` 的设备直接同签名覆盖，不必重复迁移其数据。仍使用原版的设备先保留原版。
3. **在新版恢复。** 新版打开相同的「手机备份与恢复」入口，扫描新版生成的二维码。在手机网页「从备份恢复」选择刚保存的 JSON，点击「发送到电视确认」。回到电视，在「确认恢复本机记录」勾选「同时恢复播放设置和内容分类」，再选择「合并恢复」。
4. **核对记录和更新设置。** 检查收藏、最近观看中的关键剧集和集数。在「设置 → 版本与更新」确认「自动检查并下载更新」开启。确认迁移完成后，再决定是否移除原版。

二维码窗口关闭后链接失效，最长有效五分钟；从旧版切换到新版时必须重新扫描新版二维码。恢复采用合并，不会直接清空新版已有记录。

### 使用过红果账号的设备

迁移前在旧版「设置 → 红果账号」选择「立即同步」，等待「观看记录已同步」，确认没有待同步条目。先在新版恢复本机 JSON，再重新扫码登录同一个红果账号；如需将游客进度合并进账号，可使用「合并本机记录」。

手机备份不含登录凭据、账号待同步队列、账号态本地的“整剧已看”或隐藏/删除标记。已经成功上传的账号进度可由新版重新同步；仅存在旧包本地的账号标记可能需要重新设置。因此请保留旧版，直到关键记录核对完成。

### 本机备份的范围

| 内容 | 范围 |
| --- | --- |
| 收藏 | 最多 500 部 |
| 本机/游客观看进度 | 最近 200 部剧；包含分集、位置、时长和完成状态 |
| 稍后看、隐藏推荐 | 分别最多 100 / 500 部 |
| 本机整剧已看标记 | 收藏或历史中仍存在的剧集，最多 500 项 |
| 搜索历史 | 最近 20 条，包含内容分类 |
| 播放设置 | 清晰度、倍速、自动连播、内容分类、画面模式、缓存容量；需勾选恢复设置 |

备份不包含已缓存的视频、封面、登录凭据和自动更新开关。旧版 0.14.15 与本次修复版使用相同的 `hongguotv.library` version 1 格式，没有包名或 APK 签名绑定。

## 迁移后的自动升级

发布渠道接通后，新版会自动检查和下载经过校验的同签名更新，在电视上选择「安装新版」即可打开系统安装确认。普通 Android 应用仍需用户确认系统安装；首次安装更新时可能需要按系统提示允许本应用安装未知来源应用。

后续继续使用固定包名、固定签名和递增版本码。自动检查默认开启，在前台浏览片库时启动延迟八秒检查，正常检查间隔六小时；播放时不会弹出更新打断观看。也可以随时从「设置 → 版本与更新」手动检查。

修复版独立清单为 `updates` 分支根目录的 `playbackfix.json`。只有公开 Release 附件已经完整上传并通过校验后，才更新这个清单；原版的 latest 与 KVM 渠道继续保留。完整发布机制见 [AUTO_UPDATES.md](AUTO_UPDATES.md)。
