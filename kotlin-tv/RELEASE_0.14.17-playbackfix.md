# 红果 TV 0.14.17-playbackfix 自动更新恢复

包名 `com.hongguotv.nativeapp.playbackfix`，versionCode `32`，最低 Android 8 / API 26。

## 原因

旧版从 0.12 起已有自动检查、下载、校验和用户确认安装。本轮检查时，原版 GitHub latest 与 KVM 备用源都仍返回 0.14.15-local / versionCode 30；仅合并播放修复源码不会发布新版安装包。

0.14.16-playbackfix 为避开原包签名冲突而使用独立包名，但同时关闭了自动轮询，并将手动更新页面替换为说明框。这造成修复包的功能回退。

## 修复

- 恢复修复版前台自动检查、自动下载和手动检查入口，继续保留自动更新开关、播放期间暂停、延后提醒和系统确认安装。
- 内置原版、修复版两个固定渠道，按实际包名选择；原版继续读取现有 latest 与 KVM，修复版读取 `updates` 分支的 `playbackfix.json`。
- 每个渠道只接受自己的包名；仍校验 HTTPS 来源、文件大小、SHA-256、实际 APK 包名、版本、minSdk 和已安装应用的签名。元数据不能指定任意下载地址。
- 修复版构建须显式配置保留的密钥，Debug 构建同样使用该密钥；发布工具比较前后真实 APK 的包名、签名和版本递增。
- 修复版发布不能设为仓库 latest，以免把原版引向不同包名的安装包。原版 KVM 镜像继续处理原版渠道。

## 安装

已安装 0.14.16-playbackfix：手动同签名覆盖安装本版一次即可保留数据；不需要卸载。旧包本身不发出更新请求，服务器无法让已安装的 0.14.16-playbackfix 自动获得这次恢复。

仍使用 0.14.15-local：原应用直接升级还需要原签名私钥。现有历史备份核验后属于另一个旧包，不能代替该密钥。可以保留原应用并安装修复版，使用两边「设置 → 手机备份与恢复」迁移本机记录。

修复版连续签名证书 SHA-256：`dd624bea3c779236a29c418b7a429fdc9bf1252545f9343d264b00e09802f2df`。私钥不随源码或 Release 发布。
