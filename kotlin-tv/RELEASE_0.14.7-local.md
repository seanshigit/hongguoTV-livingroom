# 红果 TV 0.14.7-local

本版针对网络抖动导致的播放重试和重复请求增加了可管理的播放缓存：播放开始后，播放器会把已读取的解密视频分段写入应用缓存目录，并在当前集播放稳定后异步预取后续分段；重复读取、短暂断网恢复和拖动回看可以优先命中本机缓存。缓存采用范围文件和容量上限，超限按最近使用时间清理，异常或不完整文件不会参与播放。

设置 → 片单与设备 → 播放缓存可以选择 64 / 128 / 256 / 512 / 1024 MB，查看已用空间，或清空缓存。缓存大小会随本机备份恢复，旧备份没有该字段时沿用 256 MB 默认值。

版本：`0.14.7-local`，versionCode `21`，最低 Android `26`。自动更新附件仍需使用与现有测试版相同的签名；电视第一次接入该更新渠道仍需允许安装未知来源应用并确认系统安装。

本地验证：核心单元测试、Android Debug Lint、Debug APK 构建通过；真实实体电视和长时间弱网播放仍需要在目标设备上复测。
