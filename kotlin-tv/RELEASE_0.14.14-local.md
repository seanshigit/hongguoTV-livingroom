# 红果 TV 0.14.14-local

版本 `0.14.14-local`，versionCode `29`，最低 Android 8.0 / API 26。APK 使用与本仓库旧版相同的本地测试签名，覆盖安装需系统确认。

- GitHub 更新清单或安装包不可用时，尝试美国 KVM 备用源；成功使用 GitHub 时以 GitHub 为准。
- KVM 定时同步已发布的 GitHub 版本，确认大小和 SHA-256 后才公布清单；同步失败保留上一版，阻止降级和同版本替换安装包。
- 电视仍核对安装包大小、SHA-256、包名、版本、最低 Android 版本和签名。已有用户数据在同签名覆盖安装时保留。
- 旧版更新器只认识 GitHub，需要先通过 GitHub 更新或手动安装本版，之后才能使用 KVM 备用源。

红果账号同步沿用 0.14.13 的实现与验证范围。实体电视和 Android 8 的升级体验仍需实机确认。
