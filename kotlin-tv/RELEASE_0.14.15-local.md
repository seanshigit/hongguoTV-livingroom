# 红果 TV 0.14.15-local

2026-11-13；versionCode `30`，包名 `com.hongguotv.nativeapp`，最低 Android 8.0 / API 26。

## 问题与修改

0.14.14 的真实取流对照中，两个漫剧和两个短剧均在播放模型阶段收到 HTTP 200 空响应，尚未进入媒体解码。首页及匿名设备注册正常。

对照 hongguo-drama v7.1（`bdab9d6158e07524f234f88c1168f20baa2cd507`）更新播放协议：

- 使用专用 Argus/Ladon 签名，覆盖最终查询串与实际发送的 gzip 正文；搜索、账号和详情签名保持原实现。
- 优先请求 video-tab GET；只有空响应才回退一次旧模型路径的 gzip POST，不将业务拒绝当成空响应重放。
- 每次取流注册匿名播放身份，避免复用可能已被消费的身份；账号的缓存设备身份不变，播放不发送账号 Cookie。
- 读取 `data.video_model_data` 和数组／字典两种清晰度列表；缺少解密信息时不当作明文视频播放。
- 保留原分段解密、备用媒体地址、Media3 官方预加载、自动连播、断点续播及更新备用源。

来源及许可见 [NOTICE](NOTICE.md)。
