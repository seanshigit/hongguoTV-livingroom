# 红果 TV 0.14.16 播放修复记录

2026-11-22；versionCode `31`，最低 Android 8.0 / API 26。

## 故障与原因

原始源码为 `52901f74586af3438e253aa03f119e43603ce73e`（公开 0.14.15-local）。对同一真实分集、同一网络各重新注册匿名设备进行比较：原 Argus/Ladon video-tab GET 配置收到 HTTP 200、0 字节；更新后的 V5 GET 配置收到 HTTP 200、22,544 字节、业务 code 0，并匹配所选分集和五档 HEVC 资源。V5 再次取样得到相同结果。

这是完整旧／新请求配置的对照，包含签名与设备参数更新，不是只替换一个请求头的单变量试验。未保存账号 Cookie、真实身份或带签名的媒体地址。

另在原版上复现独立的缓存问题：缓存键只有分集与目标清晰度，切换到另一个编码的 MP4 后可能复用旧字节；中途备用地址恢复也可能继续沿用旧文件的字节位置。

## 修改

- 为 video-tab GET 增加隔离的 V5 签名器，使用 `x-khronos`、`x-helios`、`x-medusa`；GET 以空字节的 MD5 参与签名，不发送正文或 POST 专用头。最终查询串与发送请求完全一致。
- 采用上游对应的 7.4.3.32 查询参数和匿名设备身份；搜索、账号签名保持原实现。GET 空响应才进行一次原有 gzip POST 回退，业务拒绝直接报错。
- 每份 MP4 的缓存键加入资源指纹，旧格式缓存不再被误用；中途只允许匹配原资源的备用地址继续读同一字节位置，不匹配时交回播放器重新取址。
- 资源指纹覆盖总长度、修复后完整 MP4 头以及解密后前段最多 256 KiB，属于资源一致性检查，不是完整文件校验和。
- 增加可选并存构建，安装和数据迁移方式见下文。

第三方固定提交、许可及独立测试向量来源见 [NOTICE](NOTICE.md)。

原发布签名未保存在仓库或本轮构建环境；本轮不会用不同签名冒充可覆盖升级包，也不改写旧版 Release 或自动更新清单。并存版名称为「红果 TV 播放修复版」，不使用原版自动更新渠道。

迁移本机记录：在旧版「设置 → 手机备份与恢复」用手机保存备份，再在修复版同一入口恢复并在电视上确认。收藏、观看记录等按现有合并规则导入；账号登录状态需重新建立。

## 构建

需要 JDK 17、Android SDK 36：

```bash
./kotlin-tv/gradlew -p kotlin-tv :core:test :app:assembleDebug :app:lintDebug -Phongguotv.sideBySide=true --console=plain
```

产物为 `kotlin-tv/app/build/outputs/apk/debug/app-debug.apk`。不带并存参数可构建原包名；发布签名仍需自行提供原密钥。

## 验证边界

本轮未连接实体电视，当前环境没有 Android 模拟器虚拟化设备。真实取流和 CPU 解码不能替代电视芯片的 Media3、遥控器、自动换集和长时间连播验收；Android 8 实机及所有片源没有逐一验证。仅提供 ByteVC2 且没有可用兼容资源的片源仍明确报错。
